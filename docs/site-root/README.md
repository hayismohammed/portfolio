# صفحة هوية جذر النطاق

هذه حزمة جاهزة لموقع المستخدم `https://hayismohammed.github.io/`. ليست صفحة بديلة للمعرض المنشور تحت `/portfolio/`، ولا يؤدي حفظها داخل هذا الفرع إلى نشرها على جذر النطاق.

## سبب الإعداد

في 11 نوفمبر 2026 عرض جذر النطاق صفحة GitHub Pages الافتراضية 404. ظهر اسم `GitHub Pages documentation` فوق نتيجة صفحة الدورة في ملف البحث الذي أرسله أبو فهد. صفحات المعرض الحالية تحتوي بالفعل على الاسم العربي الصحيح في `og:site_name`؛ وتوضح Google أن اسم الموقع يدعم النطاق وجذره أو النطاق الفرعي وجذره، وليس مجلد `/portfolio/` وحده. سبب اختيار Google للاسم بعينه استنتاج مرجح، وليس تشخيصًا صريحًا من Google.

## ما تتضمنه الحزمة

- صفحة عربية خفيفة قابلة للاستخدام بلوحة المفاتيح، بهوية واضحة وروابط للمعرض والدورات والأدلة.
- بيانات `WebSite` و`Person` منظمة، وعنوان أساسي يشير إلى جذر النطاق الحقيقي.
- ملف robots يسمح بالزحف ويعلن خريطتي الجذر والمعرض.
- خريطة للجذر وملف `.nojekyll`، دون تحويل تلقائي أو تتبع جديد.

## النشر بعد تفويض أبو فهد المحدد

1. إنشاء مستودع عام باسم `hayismohammed/hayismohammed.github.io` فقط إذا وافق أبو فهد على توسيع النطاق إلى هذا المستودع الجديد وعلى نشر صفحة الجذر.
2. نسخ `index.html` و`robots.txt` و`sitemap.xml` و`.nojekyll` إلى جذر المستودع الجديد، مع المحافظة على إشعار حقوق الملكية. لا تُنقل ملفات `portfolio` ولا يتغير إعداد نشره.
3. تفعيل GitHub Pages من `main` ومجلد الجذر في المستودع الجديد، والتحقق من نجاح النشر وظهور الاسم والعناصر المنظمة على الرابط العام.
4. التحقق من جذر النطاق في Search Console بالطريقة المدعومة، وطلب إعادة زحفه. عند الحاجة إلى رمز التحقق، يُستخرج من حساب أبو فهد ويُضاف بعد موافقته على النشر.
5. متابعة اسم الموقع بعد إعادة الزحف. اختيار Google للاسم آلي وقد يتأخر، ولا توجد ضمانة لتغييره فورًا.

## حدود التفويض

المسموح حاليًا هو العمل في مستودع `hayismohammed/portfolio` وفرع يبدأ بـ `rashed/`. لم يُنشأ مستودع جديد، ولم تُغيّر إعدادات Pages أو `main` في هذه المهمة. هذه الحزمة تُقدّم للمراجعة قبل طلب التفويض المحدد بإنشاء المستودع ونشره.

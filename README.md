# معرض أعمال هايس العنزي

معرض أعمال هايس العنزي وخدماته في صفحات الهبوط وكتابة محتوى المنتجات والفيديوهات الإعلانية القصيرة. يضم سبعة نماذج استعراضية، وصفحة مستقلة للدورات، ومكتبة أدلة مجانية. دورتا VoiceOver الصوتية والمصوّرة منتجان مستقلان متاحان للشراء عبر منصتيهما.

**الموقع:** https://hayismohammed.github.io/portfolio/

**حقوق الاستخدام:** نشر الشفرة للاطلاع العام لا يعني إتاحتها للنسخ أو إعادة الاستخدام؛ توجد استثناءات للأدلة المجانية للاستخدام الشخصي وفق [ملف الحقوق والترخيص](LICENSE).

## الوضع الحالي

- النماذج المعروضة للتجربة وعرض الأفكار، وليست مشاريع نفذت لعملاء.
- خدمات إعداد صفحات الهبوط وكتابة محتوى المنتجات والفيديوهات الإعلانية القصيرة متاحة للطلب. تُحدَّد المخرجات والمدة والتكلفة مع العميل قبل بدء العمل.
- لطلب خدمة أو الاستفسار: [hayis.mohammed@gmail.com](mailto:hayis.mohammed@gmail.com).
- دورتا VoiceOver الصوتية والمصورة منتجان مستقلان فعليان، وتفاصيل الأسعار والمحتوى النهائية لدى منصتَي البيع.
- لا يجمع المعرض بيانات شخصية من الزوار ولا يتضمن بوابة دفع أو نموذجًا لإرسال طلبات تجارية.

## تنظيم المعرض

- ترتيب الرئيسية: الخدمات، ثم نماذج الأعمال، ثم الدورات، ثم الأدلة المجانية، ثم النبذة والتواصل.
- صفحات النماذج تبقي روابطها مرتبطة بغرض النموذج، مع رابط واضح للعودة إلى معرض الأعمال. الأدلة التعليمية لا تظهر ضمن تذييل نماذج المنتجات والمتاجر والعيادة والمطعم والإعلان.
- روابط الدورات والأدلة تبقى في صفحات التعليم والرئيسية. الربط بين وصف مِداد وإعلانه مقصود لأنهما لمنتج افتراضي واحد.

## الفحص والتطوير

يمكن إجراء فحص الروابط الداخلية وعناصر HTML والموارد عبر:
```bash
python3 tests/check_site.py
python3 tests/check_navigation.py
python3 tests/check_public_secrets.py
```

يجري GitHub Actions فحوصًا آلية للصفحات، ومسارات التنقل، وصياغة JavaScript، والبحث الأولي عن أسرار شائعة عند طلبات الدمج والتحديثات. يوجد سجل التدقيق الحالي في [`docs/site-audit-remediation-2026-11-14.md`](docs/site-audit-remediation-2026-11-14.md). توجد أدوات فحص التفاعلات في `tests/` وسجلات نتائجها السابقة في `docs/`. سجلات الفحص المحلي لا تعني تلقائيًا أن الموقع المنشور قد اختُبر أو أن VoiceOver على iPhone قد اختُبر. اختبارات الوصول الآلية مؤشرات وليست شهادة امتثال.

يحدد صاحب المعرض الأفكار والمتطلبات، ويوجه مراجعة النماذج ونتائجها ويعتمدها، بمساعدة أدوات إنتاج رقمية وذكاء اصطناعي. معلومات الأصوات الاصطناعية موضحة بجانب الدورات والفيديو حيث يلزم.

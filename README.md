# معرض أعمال هايس محمد عقيل العنزي

صفحة ثابتة لمعرض أعمال. النماذج الخمسة علامات افتراضية للعرض، وليست مشاريع لعملاء.

الدورة الصوتية متاحة على Gumroad. النسخة المصوّرة متاحة الآن على يوديمي: https://www.udemy.com/course/voiceover-x/

رقم الجوال غير موجود في ملفات هذا الفرع. البريد ما زال ظاهرًا في صفحة المعرض مؤقتًا.

الموقع العام على GitHub Pages يُنشر من الفرع `main`.

لا يوجد في هذا المستودع موقع على Netlify.

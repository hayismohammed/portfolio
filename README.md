# معرض أعمال هايس العنزي

معرض أعمال عربي تعريفي وتجريبي يضم ستة نماذج استعراضية لصفحات ومحتوى رقمي وصفحة مستقلة لعرض الدورات، مع معلومات وروابط دورتَي VoiceOver مستقلتين متاحتين للشراء عبر المنصات المعنية.

**الموقع:** https://hayismohammed.github.io/portfolio/

## الوضع الحالي

- النماذج المعروضة للتجربة وعرض الأفكار، وليست مشاريع نفذت لعملاء.
- خدمات تصميم صفحات الهبوط وكتابة المحتوى والفيديو القصير قيد التجهيز، ولا تُستقبل الطلبات عليها حاليًا.
- دورتا VoiceOver الصوتية والمصورة منتجان مستقلان فعليان، وتفاصيل الأسعار والمحتوى النهائية لدى منصتَي البيع.
- لا يجمع المعرض بيانات شخصية من الزوار ولا يتضمن بوابة دفع أو نموذجًا لإرسال طلبات تجارية.

## الفحص والتطوير

يمكن إجراء فحص الروابط الداخلية وعناصر HTML والموارد عبر:
```bash
python3 tests/check_site.py
```

توجد أدوات فحص التفاعلات في `tests/` وسجلات نتائجها السابقة في `docs/`. سجلات الفحص المحلي لا تعني تلقائيًا أن الموقع المنشور قد اختُبر أو أن VoiceOver على iPhone قد اختُبر. اختبارات الوصول الآلية مؤشرات وليست شهادة امتثال.

يحدد صاحب المعرض الأفكار والمتطلبات، ويوجه مراجعة النماذج ونتائجها ويعتمدها، بمساعدة أدوات إنتاج رقمية وذكاء اصطناعي. معلومات الأصوات الاصطناعية موضحة بجانب الدورات والفيديو حيث يلزم.
